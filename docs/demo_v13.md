# v13 演示：历史样本 × 专家 RAG × 可追溯界面

启动现有 FastAPI 服务后，打开：<http://127.0.0.1:8000/workspace?view=history>。约三分钟可以展示以下流程。

1. 点击“真实网关历史回放”。说明这是 AAPL、2026-11-13 到期、350 行权价的固定 C/P 样本；覆盖 11 月 6、9、10 日。回放本地档案不会产生网关或模型请求。
2. 查看历史区间、来源、每日已收成交计数和每份合约的成交记录末值。指出部分交易时段覆盖未核验，因此量的变化不可比；历史 OI 缺失，不会填成零或复制今日持仓。
3. 点击“带着这段历史追问”，选择 DeepSeek，发送：“用白话复盘这几天的历史数据，标明能确认的变化和不能比较的部分，并给出专家依据。”这一步才调用模型。
4. 分别展开本地数值证据、专家来源和“专家知识是怎样找到的”。数值来自固定报告，知识来自有出处的检索块；双路排名不表示正确率。
5. 继续问：“这些数据能说明现在市场看空吗？未平仓量为什么没有给出？”观察 AI 保留历史范围、指出缺失及判断边界，而不是把看跌计数等同于看空人数。
6. 展示会话导出或重开保存的报告：历史区间、来源、引用和版本仍保留。

无需密钥也可通过本地解释演示流程，界面会明确显示本地模式。真实 DeepSeek 模式需要现有服务端配置并消耗 API 额度。教学样例和文件导入是独立入口，合成样例始终标明非真实行情。

可以这样介绍三个进步：

- **期权分析**：从展示字段进展到固定样本、可比性检查和历史复盘，缺失不再掩盖在单一情绪分数里。
- **专家 RAG**：先检索有出处的知识，再结合本地计算解释；用户能区分概念依据和数据依据。
- **界面体验**：白金风格、历史来源标签、渐进展开、手机布局及 Avatar 聊天状态保持统一。

这展示的是可核查的金融教育工作流，不是实时交易系统、预测准确率证明或投资收益承诺。完整实现及限制见 [history_rag_v13.md](history_rag_v13.md)。
