# v17 演示脚本：从期权样本获得额外信息

本脚本用于学习与课程演示。先确认当前 v17 验收报告，再按实际界面演示；不将合成数据称为真实市场，也不把试算当作收益承诺。

## 1. 先体验，后设置

打开 `/learn`。先指明“合成教学数据”及其日期、样本范围；无需 IB Gateway 或行情订阅即可学习。展示三个情景时只解释给定样本中的观察、数值依据和不能推出的结论。

可说：“这批期权告诉我们交易活动和定价结构的线索。它没有告诉我们有多少人看空，也没有告诉我们明天价格会怎样。”

## 2. 改一个假设，看清它的影响

选择买入看涨、买入看跌或看涨借记价差。指明权利金按每股报价、合约数量和演示乘数，观察总成本与到期盈亏平衡点。将到期标的价格移到亏损、盈亏平衡和盈利区域，核对图、表与结果是否一致。

可说：“股票涨了不一定代表这份看涨期权在到期时赚钱；还必须覆盖已付成本。组合降低成本时，也可能限制收益上界。”

必须补充：图展示同到期理想化现金盈亏，不能当作提前卖出期权的报价；持有到期和短腿指派仍有实际操作风险。

## 3. 带着当前输入继续追问

明确保存当前情景与试算，再进入这份报告的独立会话。发送前先展示预填问题和所选模型，由演示者决定是否发起请求。

可用问题：

- 为什么这个试算的盈亏平衡点不是行权价？
- 如果到期价不动，我在这组假设下会损失什么？
- 看跌成交比重更高，为什么还不能说多数人在看空？
- 这个价差组合的收益为什么有上限？

逐项查看合成来源、保存时间、当前输入、数值证据和专业资料。离线时展示实际模式及本地解释，不将它称为云模型成功。

可复核默认看涨试算：自然报价假设下每股权利金为 3.60 美元，固定乘数 100、合约数量 1，初始成本为 360 美元；盈亏平衡标的价为 103.60 美元。到期价设为 105 美元时净盈亏为 140 美元，设为 100 美元时损失为 360 美元。改变控件后先保存成另一份报告，再核对旧会话的快照未变。这里的数据和日期全部为合成教学输入。

## 4. 再看完整工具

转到完整工作台说明：专业网关采集、历史导入和零网关学习是不同入口。演示固定公式计算器、项目使用指南、会话导出及明确连接桌宠；强调这些入口不会自动执行交易。
