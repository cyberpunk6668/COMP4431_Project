# FinPilot v2：附加功能与创新说明

本轮对应课程列出的 Avatar integration、Fine-tuned LLM 和 User-friendly interface。课程把这些列为附加功能示例，并没有要求所有项目必须同时采用。我们的选择以能运行、能解释、能对比验证为准。

## 1. 方案选择

| 方向 | 采用方案 | 选择理由与代价 |
| --- | --- | --- |
| 形象 | Three.js WebGL2 原创程序化 3D 机器人 + SVG 2D 降级 | 真正的三维网格、相机、灯光和动画；无需外部人物模型授权或在线数字人服务。程序化角色的表现力有限，不能称为照片级数字人。 |
| 状态联动 | idle / listening / thinking / speaking / error 状态机 | 状态来自真实请求和浏览器语音事件，帮助理解系统在做什么；不是装饰性循环视频。 |
| 模型适配 | Qwen3-0.6B 上的 LoRA 监督微调实验 | 修改低秩适配器参数，保留可核验权重与训练日志；不是把提示词或 RAG 当作微调。默认仍使用 DeepSeek。 |
| 界面 | 可记忆的明暗主题、来源展开、有限 Markdown、响应式助手面板 | 把可读性、证据可查、状态清晰和设备兼容落实到具体操作。没有真实用户研究时，不宣称提高了某个百分比的用户效率。 |

不选复杂写实数字人，是因为还需要人物资产、骨骼绑定、表情/音素数据及可能的服务费用。这里优先完成可离线运行、无额外账户依赖的真实 3D 集成。模型也不盲目追求规模：本机 8GB GPU 适合小模型 LoRA，而不是训练完整 DeepSeek 模型。

## 2. Avatar 实现边界

3D 模式使用本地固定版本的 Three.js。渲染失败、WebGL2 不可用或上下文丢失时，保留可操作的 2D 形象。用户可以切换 2D/3D、减少动画；隐藏或离开视口后应暂停无用渲染。

聆听表示浏览器语音识别已开始，思考表示正在等待问答请求，朗读表示合成语音实际开始。嘴部是与朗读状态关联的程序化近似动作，没有分析音频振幅或音素，因此不应称为精准口型同步。形象组件本身不录制麦克风，也不把图像或音频发送到数字人服务。

## 3. 真实微调及可复现性

实验使用公开来源知识摘要和项目自编问题，不使用真实用户对话或 API 密钥。数据按知识主题分成训练、验证和测试，避免同一主题的中英文改写分别落入训练与测试。训练只对助手回答 token 计算损失；问题和知识上下文都被屏蔽。

训练目标是让小模型更稳定地组织金融教育回答、附带来源并说明风险。知识仍通过 RAG 提供；货币计算仍交给确定性计算器。微调不能保证金融知识正确，也不能据小样本测试声称超过 DeepSeek。

真实训练已完成，证据为 `models/finpilot-lora/training_manifest.json`、适配器文件及 SHA256。应用核对这些证据后把本地模型列为可用，实际生成还须通过独立推理链路。

| 项目 | 实测结果 |
| --- | --- |
| 数据 | 144 条训练、12 条验证、12 条测试，主题分组互斥 |
| 训练 | 3 epochs、108 个优化步骤，181.51 秒；不含安装和下载 |
| 参数更新 | rank 8，2,293,760 个可训练参数，占含适配器总参数的 0.383352% |
| GPU | PyTorch 已分配显存峰值 1912.63 MiB，不等于系统总占用 |
| 适配器 | 9,204,512 bytes；SHA256 见清单和模型卡 |
| 来源引用出现率 | 基座 8/12，LoRA 12/12 |
| 三段式结构与教育提示 | 各从基座 0/12 到 LoRA 12/12 |
| 实际网页后端本地生成 | 中文、英文及工具路由 3/3 通过；冷请求约 15.06 秒，后续英文约 10.71 秒 |

测试只有 3 个主题、2 种语言和每组 2 种问题改写，即 6 种主题-语言上下文。两种模型都获得相同参考资料，目标正文可以直接从参考复制。LoRA 的 12 条测试回答逐字匹配目标，说明本任务中的来源提取和结构化格式适配成功，不能推导开放金融推理的正确率。原离线摘录也能复制参考文本；本实验的技术贡献是完整的训练、对照评估、权重校验与部署流程，不是已经证明全面超过摘录或 DeepSeek。

首次网页部署还出现了训练提示与云端长提示不同所引入的额外泛化文句。我们保留该样本，随后共享训练和本地推理的系统提示并重新验证。最终记录在 `reports/local_integration.json`；对比原始回答、窄指标与逐条来源核对见 `reports/finetuning_evaluation.json` 和 `reports/finetuning_source_review.json`。

本地推理通过独立 Python 环境中的子进程运行，主应用不强制安装 PyTorch。权重只从预先下载的本机缓存读取，不因一次聊天自动下载大模型；启动时不把云端 API 密钥作为环境变量传入。它不是操作系统安全沙箱，进程仍继承当前用户的文件权限。模型异常或输出被截断时会明确降级为本地知识摘录。

## 4. 演示时可以怎样表达

“我们的技术贡献是把具身交互、可追溯知识、精确计算和小模型适配放进一个可复现的金融学习流程。Avatar 的状态与实际操作联动；DeepSeek 是默认引擎，LoRA 小模型是有训练记录和对照结果的独立实验。”

应分别展示：3D 网格实际渲染；2D 降级；思考与朗读事件；来源展开；明暗主题；训练清单和适配器；基座与微调后的同题回答。每项结论都对应实际记录，而不是只在幻灯片上罗列新技术名称。
