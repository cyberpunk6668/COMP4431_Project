# FinPilot v17：期权互动学习与项目体验改进

本轮目标是让初次使用者先获得可理解的信息，再选择是否查看专业细节、连接网关或发起模型解释。使用者已确认本轮完善功能、说明与交互，不加入会员收费或交易功能。

本文记录源码审计、已实现的核心逻辑与验收边界。最终 Python 回归 937 项通过；学习页与实际应用的浏览器交互分别在 3 个视口通过；真实 DeepSeek 的连续两问均首次生成通过，并完成这两答的有限语义复核。不能把这些结果当作一般金融准确率。旧版 green 报告不能代替 v17 的通过证据。逐功能清单见 [体验审计](../reports/feature_audit_v17.json)。

## 1. 入口与信息顺序

源码审计时，工作台的期权弹窗默认展开历史导入表单，位置早于专业采集表单和结果；新手首先面对文件格式、标的、日期及来源字段，难以先理解期权能提供什么信息。原 `/demo` 则是历史档案、专家检索和 AI 解释的三步证据演示，后两步依赖前序动作，不能替代零网关的互动学习入口。

v17 新增 `/learn` 学习路径。情景数据明确标为合成，用户先读“观察、依据、局限”，再尝试改变到期价格或策略输入，最后可保存并追问。专业采集、历史导入、旧演示和完整工作台继续承担原本用途；不能将合成演示伪装成新行情。

期权弹窗的最小改造原则是把学习入口和专业采集分清，历史导入默认收起，但历史深链仍应直接打开对应部分。已有结果定位功能应保留，不重复叠加滚动和动画。

## 2. 合成情景能说明什么

- 看跌成交比重更高，只描述给定合约样本的活动构成，不能当成看空人数或主动买卖方向。
- 报价差距更大，可用于解释样本内买卖价差和执行成本，不能据此断言市场必涨必跌。
- 看跌保护定价较贵，可比较指定样本的定价结构；不能把隐含波动率直接翻译成下跌概率。
- 合成未平仓量和任何变化只属于明确标注的演示输入，不能与真实存档混为一批。

数值须在本地计算，显示样本日期、合成来源和使用假设；模型不能补造缺失值、行情或胜率。

## 3. 到期盈亏试算的定义

以下只定义指定教学头寸在同一到期时刻的理想化现金盈亏，不是提前平仓估值、概率预测或买卖建议。示例使用明确给定的乘数；不能假定所有实际期权都交割 100 股。

设到期标的价格为 `S`，合约数量为 `Q`，演示乘数为 `M`，已付权利金为 `P`：

| 教学头寸 | 到期净盈亏 | 盈亏平衡点 | 理论边界 |
| --- | --- | --- | --- |
| 买入看涨 | `(max(S−K,0)−P)×Q×M` | `K+P` | 权利金为最大损失；理论收益无有限上界 |
| 买入看跌 | `(max(K−S,0)−P)×Q×M` | `K−P` | `S≥0`；最大损失为权利金，最大收益为`(K−P)×Q×M` |
| 看涨借记价差 | `(max(S−K1,0)−max(S−K2,0)−D)×Q×M` | `K1+D` | `K2>K1`、同到期且净借记有效；最大损失为`D×Q×M`，最大收益为`(K2−K1−D)×Q×M` |

试算应明确是否包含手续费。实际行权、指派、提前行权、分腿平仓、保证金、税费及可成交报价不由这张到期图模拟。图上显示范围的最高点不能冒充买入看涨的最大收益；到期盈亏平衡点也不能当成期权到期前的合理卖价。

定义核对的 primary 资料为 OIC 的 [Long Call](https://www.optionseducation.org/strategies/all-strategies/long-call)、[Long Put](https://www.optionseducation.org/strategies/all-strategies/long-put) 和 [Bull Call Spread](https://www.optionseducation.org/strategies/all-strategies/bull-call-spread-debit-call-spread)，审阅日期为 2026-11-15。采用明确的 Max Loss／Max Gain／Breakeven 部分；来源本身不验证本项目的演示输入或判断。

## 4. 保存与聊天

保存的演示报告应固定当时的情景、试算输入、公式、结果和假设。后续修改控件不能改写旧报告或旧回答。建立追问会话不能自动发送模型请求，也不能悄悄改换已有会话。

聊天中的模型解释应明确读取合成情景，给出所用证据编号；数值和到期盈亏从本地证据卡读取。离线时仍应解释当前试算的成本、盈亏平衡和损失边界；不能仅显示笼统的“服务未配置”。专业定义需要相关 OIC 依据，合成样本观察与专业知识分开标注。

现有实现仅在报告来源为 `demo`，且 `lab_context.source.kind=synthetic_demo`、两层 `synthetic=true` 时启用情景上下文。客户端不能导入该扩展或自选权利金、乘数、来源；保存接口从允许的策略与输入重新生成报告。读取情景及试算不保存会话、不访问模型或网关。保存报告、创建会话、绑定报告与发送问题保持明确分步。

每条回答的 `analysis_context.lab_context` 保留情景、教学日期、假想到期日、策略输入、公式、结果和假设的白名单快照。发送给模型的摘要排除曲线数组、完整报价表、分腿数组及任意扩展文本；精确数值仍由本地 `h.lab.*` 卡展示。模型只获得当前策略的相关到期定义。普通问题及项目使用问题仍走原有路由，不因绑定试算而强制解释期权。

离线回答会引用当前试算的成本、盈亏平衡或最大损失卡，并按已保存条件解释净盈亏；界面仍标为离线。默认看涨示例按 ask 假定买入，单份乘数为 100，初始净支付总额为 360 美元、盈亏平衡标的价为每股 103.60 美元；到期标的假定为每股 105 美元时，现金值为 500 美元、净盈亏为 140 美元。这些数字全部为人为构造条件，不是实际交易或历史收益。

三条 OIC 定义仅在合成学习回答中合并到检索语料；默认专家知识库仍为原有 14 条。新增 `expiry_payoff` 是有限的显式盈亏关系检查，不是一般语义准确率。未知引用、模型数字、缺失值、不可比变化和市场判断的原有约束继续保留；明确的“借记策略损失无限”、看涨盈亏平衡减权利金或看跌盈亏平衡加权利金也会被拒绝。

接口与副作用如下；所有写操作继续遵守现有同源限制。

| 接口 | 输入 | 结果与副作用 |
| --- | --- | --- |
| `GET /learn` | 无 | 学习页；不会发起模型或网关采集 |
| `GET /api/options-lab/scenarios` | `language=zh\|en` | 允许的情景、策略、输入约束；不落库 |
| `GET /api/options-lab/scenarios/{id}` | `put_activity`／`wide_spread`／`protection_cost`；语言 | 重新生成封闭合成报告和默认试算；不落库 |
| `POST /api/options-lab/evaluate` | 下述封闭参数 | 本地 Decimal 到期计算；不保存报告、创建会话或调用模型 |
| `POST /api/options-lab/save` | 相同参数 | 由服务器重新生成并保存新报告，返回 `analysis_id`；不自动发送问题 |
| `PUT /api/sessions/{sid}/analysis` | `analysis_id` | 明确绑定已保存报告；创建专用会话由既有 `POST /api/sessions` 完成 |
| `POST /api/chat` | `session_id`、`message`、`language`、`engine` | 仅用户明确发送后回答；省略 `analysis_id` 时继承服务器当前绑定，旧回答仍保存原快照 |

试算参数为 `scenario_id`、`strategy=long_call\|long_put\|call_debit_spread`、`strike=95\|100\|105`、`expiry_price`、`contracts`、`execution=natural\|midpoint`、`language`。`contracts` 必须为 1–10 的整数，标的到期价限制为 0–1000、最多两位小数。价差策略必须指定更高的 `upper_strike=100\|105\|110`，单腿策略不得指定该字段。权利金、乘数、来源和额外字段不能由客户端覆盖，非有限数值及布尔数量均拒绝。自然报价为买入按 ask、卖出按 bid；中间价只是可切换的假设，不能当成成交保证。

## 5. 验收与范围

最终 Python 验收运行整个 `tests/`：937 项通过、零失败、零跳过，证据为 [最终回归报告](../reports/python_regression_v17-20261115T091018432569Z.json)。测试使用独立数据库，禁用 dotenv，并在导入应用前启用网络防护，外部模型及 IBKR 请求为零。新增情景聊天测试为 67 项，包含真实失败输出的离线重放；更早的 325 项阶段结果不是最终总数。这组自动测试不能表述为实际云模型成功。

真实合成试算模型验证另存失败报告。诊断原文发现“这是一份合成教学记录”的文档身份词被数量规则误报；后续还发现“不含股息、滑点”的试算排除项被当成一般定价知识。修正仅限明确的文档身份结构及有限排除清单，不修改实际金融陈述，也不放开合约数量、金额、百分比或倍数。相同原文、原来源白名单和相同试算离线重放时，首轮原文可通过；旧模型修正曾添加的不相关 `expert.pricing` 仍被拒绝。原失败报告保留，离线重放不发新模型请求，真实模型再次验收另记。

学习页使用真实 Edge、纯计算 HTTP fixture，在 320／390／1440 视口各通过 17 项，包含三策略边界、局部图域与完整表格、数量校验、语言和键盘、请求竞争、失败重试、保存过期输入及仅预填不自动发送。此报告不测试生产持久化；对应证据为 [学习页交互报告](../reports/options_lab_ui_v17-20261115T091757419757Z.json)。

完整应用使用真实 `create_app` 与私有 SQLite、离线模式，在 320 视口通过 14 项、390／1440 各通过 19 项，共 52 项。除首页、试算、保存绑定、发送、故障恢复、计算器、手册、来源及专业入口外，390／1440 还验证了自有 CSV／JSON 的预览、实际导入持久化、显式绑定后离线问答，旧 `/demo` 的档案→检索→离线连续追问及独立会话，语言／主题跨 reload 保留与切换时草稿保留。旧版机器人 3D 在这两个宽度实际使用 WebGL2 绘制 1 帧；这是减少动态模式下的渲染证据，不是新鲸鱼娘 3D 或持续动画性能认证。每视口注入一次受控 HTTP 503 验证草稿及历史记录保留。记录无 JavaScript 错误、外部网络资产、provider 或 broker 调用；对应 [完整应用交互报告](../reports/experience_ui_v17-20261115T092152912387Z.json)。这两份报告均未访问正常 8000 服务或用户数据库。

学习页还单独核对正常显示状态下 63 个文本选择器的实际计算颜色及背景样本，最低对比度为 5.2306:1，均达到本次采用的 4.5:1 阈值，详见 [有限对比度报告](../reports/options_lab_contrast_v17.json)。检查排除装饰、禁用／加载透明度状态、其他页面和主题；不能称为全站 WCAG 认证，也不证明字体大小或整体可读性全部合格。实际麦克风输入、原生桌宠物理交互及 IBKR 权限仍未由本轮证据覆盖。

真实 DeepSeek 最终验收通过实际应用 HTTP 路由和私有数据库连续追问：两问、两次生成、零修正，详见 [最终模型报告](../reports/options_lab_live_v17-20261115T090953481424Z.json)。案例为每股执行价 100、权利金 3.60、假设到期标的价 102、固定乘数 100 的买入看涨：成本 360、到期现金值 200、净亏损 160 美元，盈亏平衡标的价 103.60 美元。回答正确解释了“标的高于执行价仍未覆盖成本”，没有将合成输入当成当前市场或收益预测。

这两答另由独立编码代理阅读全文、证据与快照，独立使用 Decimal 复算，并重新核对 OIC 原始定义，结论见 [有限语义复核](../reports/options_lab_semantic_review_v17.json)。该复核不是用户人工审批、持牌专业人员审阅或外部金融认证，也不估算模型总体正确率。整个本轮实际模型测试累计 16 个生成／修正请求，其中 7 次修正；最终本版使用 2 次生成、零修正。前 14 次失败、诊断和旧版修正结果均保留，没有删掉失败只报最终成功。

验收至少包括：三种策略的独立手算、盈亏平衡、数量／乘数、边界和非法输入；三场景的来源标识、指标及可比性；320／390／1440 视口、键盘、请求竞争、错误恢复；保存后改参数仍保留旧报告；连续追问仍引用原批次。普通聊天、三类计算器、手册、来源、语言、主题、Avatar、旧演示与共享会话须分别回归。

新的桌面网页不能视为新的 Windows 物理拖动／穿透认证。真实行情权限仍属于原网关路径；零网关演示不能证明账户已具有实时订阅。模型成功调用也不证明金融结论必然正确。
