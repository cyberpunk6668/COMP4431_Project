# FinPilot 期权易懂解读

普通用户进入期权分析时，先阅读数据状态和白话结论，再按需要查看解释、依据和专业详情。分析围绕当前选定的标的、到期日及行权价样本组织。信息层把已有期权统计转换成可核对的问题与回答，并保留证据入口。

## 阅读顺序

1. 数据状态说明这份资料的时点、行情模式和可用程度。
2. 白话结论说明本批数据能支持的观察，并解释它对阅读结果的影响。
3. 问答卡把合约成交、集中位置、相对定价和信号分歧分别展开。
4. 用户可以打开专业详情、模型报告与证据，核对计算口径和原始合约。

延迟行情与冻结行情具有各自的时点含义。界面应把行情模式和数据完整性分别表达，本地刚收到数据也不能直接证明交易所行情没有延迟。 [IBKR 行情类型](https://www.interactivebrokers.com/docs/tws-api/doc/md/delayed-data)

## 用词与统计单位

| 专业概念 | 易懂解释的口径 |
| --- | --- |
| 看涨与看跌期权 | 合约赋予买方按约定条件买入或卖出的权利。合约类型与交易者买卖动机需要分别理解 |
| 成交量占比 | 解释为本批已成交合约中两类合约的构成，分母只使用满足配对条件的样本 |
| 未平仓量 | 解释为尚未结束的合约存量，保留其独立更新周期 |
| 报价覆盖 | 解释为本次请求中有多少合约提供了可用报价 |
| 买卖价差 | 解释为显示买价与卖价之间的距离，可帮助理解报价紧密程度 |
| 隐含波动率 | 解释为从期权价格推算的波动程度；阅读时同时关注所选到期日和数据质量 |

“每一百份”图解使用合约数。成交一份合约时存在买方和卖方，合约数不能换算为投资者人数。看跌或看涨合约成交更多，只说明该类合约在本样本内更活跃。 [SEC 期权入门](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-63)

未平仓量统计未结束的合约，OCC 在清算和配对开平仓后更新相关数据。将成交与存量一起阅读可以发现结构差异，解释动机仍需更多信息。 [OCC/OIC 未平仓量说明](https://www.optionseducation.org/referencelibrary/faq/general-information)

隐含波动率来自当前期权价格及定价模型。文字层解释定价中反映的波动程度，保留样本与到期范围。 [OIC 波动率说明](https://www.optionseducation.org/referencelibrary/faq/technical-information)

## 需要保留的状态区别

- 未收到值与实际收到零值分别呈现。没有有效分母时不生成占比。
- 行情延迟与报价缺失分别解释。前者影响时点，后者限制可比较范围。
- 证据分歧与证据不足分别解释。分歧表示可用观察强调了不同侧面；不足表示计算或比较条件尚未满足。
- 多组报告保留各组的标的、到期日和采集时间。白话概览以当前样本为范围。
- 模型生成文字与本地统计依据保留各自来源。用户可以逐项回到证据阅读。

## 信息层实现

服务端在已有 `snapshot`、`quality`、`metrics` 和 `collective` 之上生成 `plain_brief`。单组报告保留标的和到期日范围，联合报告保留各组自身的范围与时点。白话内容依赖已计算的合格字段，因此关闭云端模型时仍可使用。

`plain_brief` 提供标题、结论、数据状态、问答卡、后续阅读提示和术语解释。卡片同时携带证据编号，界面可以从白话结论定位回原始依据。“每一百份”图解只在有效成交总数大于零、配对覆盖满足条件时显示，零与缺失各有对应文字。

界面默认使用「易懂解读」。更改日期、约定价格范围及行情类型放在折叠设置中。专业用户可切换「专业详情」查看原有统计结构，用户也可打开单条结论的依据，而无需先阅读整张合约表。

当前账户遇到实时权限不足时，界面提供明确的延迟资料选项，仍由用户触发下一次请求。结果按照实际收到的行情类别显示。

## 验证记录

2026 年 11 月 11 日，服务端完整测试通过 138 项。白话层包含 17 项计算与语义测试，API 整合包含 8 项测试。检查了延迟和冻结类型、过时与未知接收时间、混合行情、零与缺失、覆盖不足、共同样本、对比失败，以及同一快照的证据引用。结果保存在 `reports/tests_v8.xml`。

Edge 的界面任务检查在 320、390 和 1440 像素视口通过 18 项检查。验证默认易懂视图、折叠设置、数据状态位于结论之前、问答卡、每一百份图解、专业视图切换、阅读偏好保存、术语解释、证据跳转、权限失败后的显式延迟重试，以及中英文和移动布局。此项使用受控响应和实际白话层生成器，报告保存在 `reports/options_novice_browser_v8.json`，截图位于 `reports/screenshots/options-v8/`。

`reports/options_novice_smoke_v8.json` 使用合成输入验证白话报告，未发起外部请求。`reports/options_novice_cloud_v8.json` 使用匿名合成汇总证据验证真实 DeepSeek 的补充解释。两类结果分别记录。

本轮验证覆盖计算口径和界面操作，还未开展由非专业参与者完成的可用性研究。页面中的普通语言、分层阅读和术语解释旨在降低阅读门槛，实际理解程度仍需结合用户反馈评估。

真实 IB Gateway 的两组延迟数据也经过易懂解读流程，综合状态为资料有限。该测试保留状态与卡片编号，记录于 reports/options_novice_gateway_v8.json。
