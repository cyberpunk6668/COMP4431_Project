# FinPilot v16：项目使用帮助与教程事实清单

本文记录 v16 已实现的项目自助教程、实际入口、回答边界及验证证据。最终离线回归 **763 项通过**，320／390／1440 三种视口各 **18 项**受控界面检查通过；两轮真实 DeepSeek 主题匹配均通过，最终步骤逐字来自已审阅手册。v15 桌宠及更早报告保留为历史阶段证据，不与本次结果混用。

完整结果索引见 [v16 综合验收](../reports/project_help_acceptance_v16.json)。本机 `127.0.0.1:8000` 已加载最终后端，公共手册路由与当前手册逐项核对通过，见 [运行服务检查](../reports/project_help_runtime_v16.json)。更新后刷新工作台；原生桌宠重启后加载新页面，服务重启后的会话共享需再次明确连接。

## 1. 帮助功能做什么

用户可以在工作台或桌宠中询问“这个项目怎么用”“历史复盘在哪里”“怎么导出当前会话”等操作问题。帮助回答的步骤、按钮、链接和限制来自固定的本地审阅手册；模型如参与语义匹配，只能选择白名单主题 ID，不能自行发明操作步骤、HTML、文件路径或外部链接。

新增页面为 `/help`。接口契约如下：

| 接口 | 内容 |
| --- | --- |
| `GET /api/project-help?language=zh` | 手册目录，包含 `manual_version`、`current_version` 和 `topics` |
| `GET /api/project-help/search?q=历史复盘&language=zh` | 受限主题搜索，返回已知 `topics` 和手册版本 |
| `GET /api/project-help/topics/help.history?language=zh` | 一个白名单主题的步骤、功能链接和限制 |
| 聊天中的教程回答 | `mode=project-help`，`project_help` 保存手册、步骤、来源及 `selector` 实际匹配状态 |

已绑定期权报告的会话也可以询问项目操作方法：该类问题不应交给金融分析生成器，不改写当前 `active_analysis_id`，也不触发新行情采集。它与“这批数据说明什么”是两种不同请求；后者继续使用报告的金融证据与专家知识路径。

主题包括项目概览、计算器、期权、历史复盘、报告追问、模型、桌宠、导出、语音、形象、RAG、普通聊天、外观、IBKR、交易能力及未知边界。来源 ID 使用 `help.*`，不是样本数值的 `h.*`／`change.*`，也不是专业知识的 `expert.*`。来源链接指向可读手册的固定锚点，例如 `/help#help.models`；主题 API 仍可单独读取，不能由输入拼成任意服务器文件地址。

本地规则先识别项目使用意图及必要主题。在线且所选引擎可用时，模型读取这些真实功能的手册数据，最多请求一次主题 ID 匹配；它只能从候选白名单选择，并保留已识别的必要主题。未知 ID、漏掉必要主题、自由操作文字或其他无效 JSON 会退回本地手册，不自动重试。离线、模型不可用及未确认能力仍有如实说明。浏览目录、搜索手册和点击只填入问题的入口不请求模型或 IBKR。

回答的步骤、链接和限制由手册原文组装，而非模型自由生成。`selector.engine`／`status` 区分 DeepSeek、可选本地 LoRA 与本地手册；`generation_attempts` 记录匹配尝试。`grounding.model_generated_steps=false`。项目教程不是金融市场的 RAG 证据，也不是对 DeepSeek 进行微调。

保存会话时，教程上下文附在既有 `sources` JSON 的首个来源中；重新读取会话时恢复为消息的 `project_help` 字段，不新增数据库列。它不占用市场分析的 `analysis_context`。工作台、桌宠和演示页共用安全 DOM 教程卡；完整原文保留给复制／朗读，可见步骤仅显示一次。桌宠的完整指南使用同面板 API 视图，不扩展原生桥、CSP 或麦克风权限；原生宿主继续使用 15.0.0，应用后端为 16.0.0。

## 2. 实际入口与按钮

默认端口是 8000；如启动时改端口，以下本地地址也需相应修改。网页应通过后端打开，不应直接双击 HTML 文件。

| 想做什么 | 已核对的入口／按钮 | 关键限制 |
| --- | --- | --- |
| 进入首页 | `/`，FinPilot 品牌首页 | 首页动画不等于实时市场图表 |
| 金融或普通问答 | `/workspace` →“知识助手”→输入→“发送”；Enter 发送，Shift+Enter 换行 | 根据实际模式区分 DeepSeek、本地 LoRA、离线响应和计算工具；不假称联网查到最新新闻 |
| 复利储蓄 | `/workspace?tool=compound`，或“财务计算器”→“复利储蓄” | 固定名义年利率、月复利、每月月末追加；不含税费、通胀和市场波动 |
| 贷款月供 | `/workspace?tool=loan` →“贷款月供” | 固定利率等额本息，不含额外费用、提前还款和变动利率 |
| 月度预算 | `/workspace?tool=budget` →“收支预算” | 同一币种、同一月度口径；不是自动读取银行账单 |
| 默认计算器 | `/workspace?view=calculator`，或输入区旁“计算” | 默认打开复利，不是独立股票交易计算终端 |
| 期权样本分析 | `/workspace?view=options`，或侧栏“期权分析”→“帮我读懂这批期权” | 实际会请求网关，受登录、接口、权限、报价类型和覆盖条件影响 |
| 单组／批量期权 | “你想了解什么”选择单公司／基金或对比清单；批量最多四行 | 每行代码及可选到期日，提交前校验实际链日期；不是无限全市场扫描 |
| 到期日／范围／行情类型 | 展开“调整日期、范围与报价时间”→“读取可选到期日” | 读取的是实际期权链到期日，不是任意日历日期，也不能把到期日等同于所有结算时点 |
| AI 综合解释 | 期权表单“让 AI 补充解释” | 勾选后可把汇总交给模型；质量不足时仍须保留限制，不保证可成交双边报价 |
| 历史复盘 | `/workspace?view=history`；位于期权弹窗内“历史复盘与专家依据” | 是历史复盘，不是即时行情或完整期权链 |
| 真实历史存档 | “回放真实 IBKR 历史样本” | 回放服务器已存档资料，不重新访问网关，不自动调用模型 |
| 教学数据 | “加载教学样例” | 是明确标注的合成数据，不能称作真实市场记录 |
| 导入历史资料 | “选择 CSV / JSON 文件”→核对预览、代码和到期日→“生成本地历史复盘” | 最多 300 行、32 KB；当前支持 USD、标准乘数 100；不是任意 Excel／PDF／图片上传分析 |
| 获取导入格式 | “下载 CSV 模板”或“下载 JSON 模板” | 模板只有字段或空清单，不含市场数据 |
| 带报告追问 | 快照“针对这批数据追问”，或历史“带着这段历史追问” | 先绑定已保存报告并预填问题，仍需用户点击发送 |
| 聊天中刷新 | 当前快照卡“刷新并解释变化” | 真实重新采集与模型解释，保留旧报告；历史报告不能借此伪装成实时更新 |
| 查看来源 | 回答中的数值依据、专家来源；或“知识来源”及 `/workspace?view=knowledge` | 当前知识来源目录不是任意文档上传／在线新闻搜索器 |
| 模型切换 | 输入区“回答引擎”选择器；桌宠也有引擎选择 | 只影响后续回答；本地 LoRA 不可用时应明确禁用／提示，不是微调托管 DeepSeek |
| 语言与主题 | 顶部 EN／中文、主题按钮及“减少动态” | 切界面语言不会重写旧回答；减少动态不关闭文字功能 |
| 导出会话 | 当前会话下方“导出会话 ↗” | 导出 JSON；没有会话 PDF、Excel 或一键导入聊天恢复按钮 |
| 新建／恢复／删除 | 顶部“新建会话”、侧栏最近会话及删除按钮 | 删除不可恢复；导出的 JSON 不等于已实现的导入功能 |
| 语音输入 | 网页“语音输入” | 取决于浏览器与权限；识别结果只填入草稿，仍需发送，可能依赖浏览器厂商服务 |
| 朗读回答 | 回答的“朗读回答”或助手面板“朗读最新回答” | 浏览器需支持；角色动作不是音素唇形同步 |
| 角色展示 | 助手“展示形象”→“鲸鱼娘 · 2D”或“原有机器人 · 2D/3D” | 鲸鱼娘没有新建 3D 版本；旧机器人 3D 依赖 WebGL2 |
| Windows 桌宠 | `powershell -NoProfile -ExecutionPolicy Bypass -File .\start-desktop.ps1` | 便携 EXE 仍需要项目 Python 后端，不是无需 Python 的单文件产品 |
| 共享桌宠会话 | 工作台选好会话→“连接当前会话”；桌宠可继续提问 | 不扫描其他会话；网页切换到别处不会自动更换桌宠连接；断开不删除聊天 |
| 桌宠互动 | 单击互动，双击／回车开面板；菜单／托盘隐藏、恢复、缩放、退出 | 这些动作本身不调用模型；本期不提供桌宠麦克风或读屏电脑操作 |
| 独立创新演示 | `/demo`：载入真实历史档案→检索专家依据→明确点击 AI 解释 | 独立演示会话，不自动加入桌宠共享，不读取已有聊天 |
| 接口说明 | `/docs`；机器契约 `/openapi.json` | 属于接口说明，不应被当作已经完成所有网关权限配置 |

## 3. 几个容易问错的操作

**“我只想看看项目怎么用，会不会刷新行情？”** 教程本身只解释已核对的功能。打开入口、预填问题和阅读手册不能等同于点击执行分析。常见操作回答应说明下一步是否会请求网关或模型。

**“历史页面能直接抓取指定几天的网关资料吗？”** 后端存在有界历史 fetch API，但当前历史网页表单只提供存档回放、教学样例和文件导入，不能虚构“输入天数后点抓取”的网页按钮。新资料应使用真实已提供的接口或合法导出文件，不把存档回放说成新采集。

**“年利率 5% 要填多少？”** 计算器年利率字段填 `5`，不是 `0.05`。这是本项目输入单位，不能据此把名义年利率解释成已经包含所有费用的 APR。

**“为什么没有报价，是不是肯定没买 OPRA？”** 项目可以展示网关和数据质量信息，但不能从当前提问直接查明账户套餐或把所有缺失归因于同一原因。实时权限、延迟行情、接口连接和字段缺失须分开说明；已有历史存档可以回放，不意味着所有历史数据都免费或无需权限。

**“切到本地模型是不是在微调 DeepSeek？”** 不是。本地实验引擎是独立的 Qwen3-0.6B LoRA；DeepSeek 是托管 API。RAG、提示词和界面切换都不能冒称为微调 DeepSeek。

**“桌宠表情能告诉我现在应该买还是卖吗？”** 不能。它表示处理、朗读、互动或错误状态，不是市场情绪、交易信号或置信度。金融说明仍需读取实际报告、数据日期和依据。

## 4. 不应被教程声称已经实现的能力

- 自动交易、自动下单、自动登录券商或读取用户账户／密码／验证码。
- 全市场实时行情保证、准确预测涨跌、保证收益，或凭历史合约计数断言当前多数人观点。
- 网页端任意 Excel／PDF／图片知识库上传、互联网新闻／社交媒体情绪抓取及自动联网核查。
- 将聊天导出为 PDF／Excel，或直接把导出 JSON 导入恢复成聊天。
- 自定义训练托管 DeepSeek、自动下载和训练新模型。
- 新版鲸鱼娘的真实 3D、精准音素口形、桌宠麦克风、屏幕读取、键鼠代理与自动电脑操作。
- 无需 Python 的完整独立产品、所有 Windows／手机硬件认证，或所有物理拖动和精确透明命中已经认证。
- 商业化使用本轮鲸鱼娘素材的无限授权；素材仍按非商业及归属条件使用。

对未确认功能，帮助回答应明确未实现／未确认，并给出当前真实可用的相邻入口，不用“应该有”“点击某个想象中的按钮”补全。

## 5. 手册依据与验证方法

手册回答可携带手册版本和固定源码白名单的审阅／当前哈希。哈希用于追溯实际依据和发现代码变化，不能自动证明每句教程语义正确。固定 `help.*` 来源与白名单入口仍需逐条核对界面。

功能验收清单位于 [project_help_cases_v16.json](../evaluation/project_help_cases_v16.json)。其中事实与禁止主张供人工语义核对，主题 ID 和固定路径可机械检查；这不是检索模型准确率、金融预测胜率或第三方盲测。

建议按以下顺序验收：

1. 无模型／IB 的目录、搜索和主题读取；未知 ID、路径穿越和模型自由文本不能生成新入口。
2. 工作台与桌宠都能询问项目操作；已绑定历史报告仍保持同一分析身份，教程不会覆盖或刷新它。
3. 动作链接只导航或预填，涉及模型／网关的执行步骤仍需明确操作；失败回退标明实际模式。
4. 普通金融概念、普通科学问题和显式计算命令继续走原有能力，不被教程分类器全部截走。
5. 模型若参与辅助主题选择，只能命中白名单，最终步骤来自手册；网络失败、未知主题和无关输出不能伪造功能。
6. 英文、移动视口、键盘焦点、来源展开和 `help.*` 点击行为分别核验；不把 `/demo` 的独立会话强行加入桌宠。
