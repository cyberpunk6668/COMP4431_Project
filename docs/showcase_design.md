# FinPilot 交互动效展示页：设计与验收说明

本轮将项目入口升级为黑金色的功能叙事展示页，原有金融工作台保留在 `/workspace`。目标是让访客通过视觉和操作理解项目的真实能力；“获奖级”是设计方向，不是已经获得奖项或通过第三方评级的事实。

## 1. 如何采用两份参考

两份参考分别要求浅色金色与纯黑金色，它们不能同时作为同一首屏的精确底色。本实现选择第二份的黑金主视觉，同时参考第一份的大字号、分层入场和清楚的双按钮层级。

基础色为纯黑、近黑容器、白色与柔和灰，金色用于关键文字、轮廓、交互状态及视觉焦点。页面保留 FinPilot 身份，不改成 Coinwise 或 ARAISE。参考中的加密货币交易、收费套餐、营销增长承诺、虚构客服资料和订阅表单，没有对应的真实后端能力，因此改为金融教育、来源检索、精确计算、Avatar 和双模型实验。

首屏的主要视觉是原创程序化 WebGL2 雕塑，二维 SVG 作为加载和失败时的后备。它不是行情图或收益预测。参考视频不应成为首屏文字或导航可用的前置条件。

## 2. 动效承担的功能

| 位置 | 视觉与动效 | 帮助理解的内容 |
| --- | --- | --- |
| 首屏 | 金色空间轨道、文字分层入场、按钮反馈 | 提出项目主题并提供直接进入工作台的入口 |
| 功能章节 | 随滚动切换的四阶段叙事 | 从问题、证据、计算到解释的完整流程 |
| 来源演示 | 可选择的真实知识条目与官方链接 | 用户能追溯知识，而非把装饰动画当成依据 |
| 计算计划 | 可调参数、数值结果与情景图 | 改变假设会改变复利结果，数值来自实际计算接口 |
| Avatar 与模型 | 真实形象演示及独立模型实验说明 | 区分交互形象、云端模型和本地微调的作用 |
| 行动入口 | 场景链接、问题草稿和计算器深链 | 展示页能进入实际工具，而不是只有营销按钮 |

入场采用 GSAP 时间线；ScrollTrigger 负责滚动显现和首屏视差。四阶段叙事使用 CSS sticky 与原生滚动事件，在 requestAnimationFrame 中计算阶段进度。移动菜单使用 Motion 的存在/退出过渡。它们共享暂停和减少动画的原则，避免不同动画系统各自持续运行。页面不劫持浏览器滚轮，也不以等待影片加载的方式锁住输入。

## 3. 技术结构

- `frontend/`：React、TypeScript、Vite 与 Tailwind CSS 的可编辑源文件。
- `web/showcase/`：构建后的本地资源，由已有 FastAPI 提供。
- `/`：功能展示页；`/workspace`：保留原金融助手工作台。
- 页面仅读取 `/api/showcase`、`/api/knowledge` 等功能/知识元数据，并在用户调整情景时调用 `/api/calculate`。展示过程不自动提交聊天，不消耗 DeepSeek 额度，也不启动本地模型推理。
- 工作台深链只设置问题草稿或打开对应工具，用户仍决定是否发送问题。

依赖使用项目 `frontend/package.json` 和锁文件固定版本。实施时核对的版本为 React 19.3.1、Vite 8.3.7、Tailwind 4.3.5、GSAP 3.15.1、Motion 14.12.0、Three.js 0.187.0。前端资源和字体在本地提供，核心交互不依赖运行时 CDN。

## 4. 动效、设备与内容降级

系统的 `prefers-reduced-motion` 偏好会抑制大幅位移、视差和自动旋转，同时保留可读文字、按钮及静态视觉。用户也能主动暂停非必要动画。WebGL2 创建失败时保留 SVG，JavaScript 不可用时仍提供静态标题和工作台链接。

3D 渲染限制像素比与绘制频率，在页面隐藏、场景离开视口、用户暂停或减少动画时停止不必要的帧循环；组件卸载释放几何体、材质、纹理和渲染上下文。上述是资源管理措施，不是对所有设备帧率或耗电的保证。

键盘可进入菜单与工具。移动导航提供展开状态、Escape 关闭和焦点返回；链接与按钮具有可辨识焦点。底部采用用户提供的参考视频作为静音装饰，标注为非市场数据，并随暂停、减少动画和可见性停止播放，不作为等待用户或锁住输入的开场。

## 5. 金融与评估口径

页面中的复利结果是名义年利率按月复利、月末追加投入的假设计算，未计税费、通胀或市场波动。典型核对情景为本金 10,000、年利率 5%、10 年、每月 500，期末金额 94,111.23。不能把该曲线解释为投资收益承诺。

LoRA 只展示项目实际记录。12 个留出问题的引用/格式结果属于小型、来源条件下的行为评估，不等同于金融事实正确率、用户研究或优于 DeepSeek 的结论。展示页不会虚构使用人数、客户徽标、收益率、价格或商业服务。

## 6. 验收与证据

可复用浏览器脚本为 `scripts/check_showcase.py`，报告为 `reports/showcase_check.json`。测试覆盖实际 CSP 下的渲染、暂停/恢复、减少动画、离屏停止、WebGL 失败、无 JavaScript、移动导航、六种屏宽、真实计算接口和工作台深链。

最终构建已于 2026-11-10 在本机 Microsoft Edge 无头浏览器执行，24/24 项检查通过，耗时 23.08 秒。测试在实际 FastAPI CSP 下运行，正常路径无页面错误、控制台错误、外部运行时资源请求或聊天调用。

| 验收方向 | 实际证据 |
| --- | --- |
| 真实动画 | WebGL2 场景实际绘制；全局暂停、恢复、减少动画及离开视口时的帧计数符合预期 |
| 滚动叙事 | 原生滚动驱动阶段变化；减少动画时四个章节仍可手动选择 |
| 财务计算 | 真实接口结果 94,111.23；键盘改变利率；零本金和零投入时的数值与图形端点一致 |
| 屏幕尺寸 | 320、390、768、1024、1440、1920px，首屏和计算区均无横向溢出 |
| 导航 | 手机菜单展开、Escape 关闭、焦点返回，以及问题、计算器、知识库和模型深链 |
| 降级 | 强制禁用 WebGL2、阻断 Three.js 分块、禁用 JavaScript 后均保留对应 SVG 或基本正文入口 |
| 有意故障 | 测试主动中止一次 Three.js 请求，产生一条预期网络控制台错误，单独记录，不混入正常路径错误统计 |

最终报告含 9 个前端源文件与 21 个构建文件的 SHA256，复核时均与当前文件一致。报告 SHA256 为 `189366e860ad0dac7d7481a26a37ca2a6813c76c6c2a21d0ada3914dbf111530`。后端验证独立记录于 `reports/tests_v3.xml`，本轮为 58/58 通过。

截图保存在 `reports/screenshots/showcase/`，包括桌面与移动首屏、滚动章节、来源卡片和实际计算情景。浏览器加载时延和绘制次数仅作为本机观测值，不宣传为 Lighthouse、Core Web Vitals 或完整 WCAG 认证，也不代表已经获得设计奖项。
