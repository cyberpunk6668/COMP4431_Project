# FinPilot 浅色视频首页设计与验收

首页采用用户提供的 Coinwise 视觉参考。浅色背景、深色标题与金色强调构成首屏的主要层次，参考视频承接主视觉。主按钮采用深海军蓝文字以增强在金色背景上的辨识度。页面中的名称、文字和入口对应 FinPilot 的金融学习功能。

## 首屏动效

GSAP 时间线在媒体就绪或进入回退时启动。导航从上方进入，眉题、主标题、说明和操作区从下方进入，五组的起始位置分别为 0.2、0.3、0.4、0.5 和 0.6 秒。各段持续 1 秒，使用 `power3.out` 缓动，完整时间线为 1.6 秒。低于 1024px 时显示移动导航。Motion `AnimatePresence` 处理菜单进入和退出，键盘可打开菜单，在菜单中循环移动焦点，并按 Escape 返回触发按钮。 [GSAP Timeline](https://gsap.com/docs/v3/GSAP/Timeline/) · [Motion AnimatePresence](https://motion.dev/docs/react-animate-presence)

背景视频来自用户提供的参考文件，构建后由同一 FastAPI 服务提供于 `/static/showcase/media/reference-motion.mp4`。视频静音、循环、行内播放。媒体失败或等待达到 2.5 秒时，静态海报继续承载标题与操作入口。迟到的视频仍可恢复播放，文字保留在完成入场的位置。页面暂停控件和系统减少动画偏好控制播放，首屏离开视口或标签页隐藏时暂停。系统深色偏好下仍呈现浅色设计。 [W3C Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)

静态海报截取自同一视频的约 1.92 秒画面。视频来源与文件 SHA256 记录在 `frontend/public/asset-provenance.json`，构建时复制到本地部署目录。浏览器直接读取项目中的媒体与字体文件。

## 功能体验

首屏操作分别进入 `/workspace` 和页内 `#experience`。下方继续提供四阶段功能体验、知识来源、复利情景、可切换的虚拟教练和模型入口。

来源链接来自本地知识库。复利结果由 `/api/calculate` 计算，例如本金 10,000、年利率 5%、期限 10 年、月末投入 500 的期末金额为 94,111.23。工作台深链打开相应工具、选择可用引擎或填写问题草稿，发送问题由用户操作。示例结果采用固定名义利率并按月复利，未计税费与通胀。

## 浏览器复现

启动 FinPilot 后，在项目根目录运行以下命令。脚本使用本机 Microsoft Edge，环境依赖见 `requirements-ui-tests.txt`。

```powershell
.\.venv\Scripts\python.exe scripts/check_showcase_v5.py
```

2026 年 11 月 11 日，本机 Microsoft Edge 无头浏览器完成 18 项检查，测试用时 18.19 秒。脚本在实际 FastAPI 内容安全策略下运行，正常场景的页面异常、控制台错误、外部运行时请求及聊天调用均为零。报告单独记录人为制造的媒体 404。

| 验证内容 | 结果 |
| --- | --- |
| 视频与入场 | 本地参考 MP4 哈希匹配，浏览器解码并推进播放时间。依次观察到五组元素从隐藏、位移到完全可见，相邻出现时间间隔约 100 毫秒 |
| 故障回退 | 媒体 404 和 2.5 秒等待上限均保留标题与工作台入口。恢复迟到请求后视频就绪，首屏保持可见 |

| 响应式 | 320×568、390×844、768×1024、1023×900、1024×900、1440×1000、1920×1080。七组首屏均与视口等高，标题与操作区在首屏内，计算区无横向溢出 |
