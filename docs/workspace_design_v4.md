# FinPilot 黑金工作台：设计与验收记录

日期：2026-11-10。范围：现有 `/workspace` 的界面、动效及交互整合；首页继续使用已有黑金展示页。本文对应代码与本轮验收，不把视觉风格等同于获奖、投资准确性或完整无障碍认证。

## 1. 设计目标与页面结构

工作台延续首页的深黑背景、金色强调、Inter 字体与细边框。深浅不同的表面区分导航、对话、输入区、计算器与 Avatar 面板；正文保持可读的中性灰白，金色用于选择、执行及焦点反馈。金色不代表收益或市场行情。

桌面保留左侧会话导航、主工作区和右侧交互助手。移动端将导航收进抽屉，并允许展开、折叠助手；对话输入、模型选择和计算入口始终可操作。320、390、768、1024、1440、1920px 为本轮检查宽度，不据此推断所有设备表现。

首页与工作台各自采用已有技术结构：首页 React/Vite，工作台为 FastAPI 提供的语义 HTML、CSS 与原生 JavaScript，Avatar 按需使用本地 Three.js。统一视觉不要求重写已有稳定的业务接口。

## 2. 状态与动效契约

| 功能 | 用户反馈 | 状态与保护 |
| --- | --- | --- |
| 聊天 | 输入区聚焦、等待指示、回答轻量进入、来源展开 | 请求期间锁定模型、语言和会话切换；失败显示原因并保留草稿 |
| 模型切换 | 名称、说明、选择状态及确认反馈同步变化 | 不可用模型禁选；实际响应模式单独显示，不能仅凭下拉值宣称调用成功 |
| 计算器 | 弹窗进入、工具切换、结果卡与曲线呈现 | 输入由原生约束检查，结果由后端固定公式返回；序号校验拒绝过时响应 |
| Avatar | 黑金 2D/SVG 与真实 3D/WebGL 视觉；聆听、思考、朗读和待机状态联动 | 3D 不可用时保留 2D 路径；异步完成恢复待机，错误状态与提示一致 |
| 移动导航 | 抽屉与遮罩配合 | Escape、遮罩关闭、焦点返回、键盘焦点约束及背景不可交互 |

进入与状态变化使用 Web Animations API，基础时长为 280ms；计算结果卡按 35ms 错开，曲线描边为 600ms。模型选择区使用 450ms 的轻量确认反馈。数值不做伪实时滚动，避免误导为市场报价。

这些效果用于解释动作和层级。聊天接口返回完整答案后再显示回答进入动画，本轮不宣称逐 token 流式生成。语音状态联动也不意味着所有浏览器都有可用的识别服务。`setBusy()` 同时禁用旧回答朗读；`readAloud()` 也检查忙碌状态，避免语音播放覆盖思考状态。

计算工具切换、参数编辑和新计算都会更新 `calculationSequence`。只有序号仍匹配的响应、错误与 finally 状态可以更新界面；编辑已显示结果的参数后先隐藏旧结果，防止新输入与旧结果被误认为同一情景。

暂停动效由 `#workspace-motion-toggle` 控制，系统 `prefers-reduced-motion` 同样生效。有效减少动效状态以 `html[data-motion="reduced"]` 表达：停止非必要循环动画及 3D 连续帧，同时保留内容与操作。测试同时检查 3D 帧计数与 CSS 无限动画。

## 3. 兼容与偏好

- `finpilot-workspace-skin=gold-v4` 是一次性迁移标记。首次升级把旧版浅色默认迁移到黑金深色；标记存在后继续尊重 `finpilot-theme` 中的用户选择。
- 本地字体、Avatar 代码和 Three.js 由应用自身提供，工作台不依赖外部字体或图形 CDN。浏览器语音服务是独立的系统能力。
- 计算器保留复利、零利率、等额本息和预算缺口情景；计算假设、公式及风险说明与结果一起展示。
- 财务知识回答保留 Markdown 安全渲染、可点击引用及来源摘要；已有回答不会因界面语言切换而自动翻译。
- API 凭据由服务端读取，页面、导出与本报告不记录密钥。UI 模型名称不暴露服务器密钥或无助于用户判断的调试信息。

## 4. 验证方法

运行本地服务后执行：

```powershell
.venv\Scripts\python.exe scripts\check_workspace_v4.py --base http://127.0.0.1:8000
```

开发阶段可加 `--skip-live-chat`，只运行独立模拟故障和真实本地功能，避免重复产生云端推理费用。默认完整运行最多提交两条公开、合成的金融教育问题：桌面中文、390px 移动英文。脚本只清理自身创建并持有 ID 的测试会话。

| 层级 | 实测范围 | 证据边界 |
| --- | --- | --- |
| 真实 Edge + 本地后端 | 六档响应式宽度、导航、主题迁移、2D/3D、暂停动效、计算与会话增选删导出 | 一台 Windows 的浏览器环境；不是所有手机或浏览器的性能保证 |
| 真实 DeepSeek | 两次正常双语回答、实际模式、来源、完成后恢复待机、保存与导出 | 不作为广义金融事实准确性基准 |
| 独立模拟后端 | 延迟等待、503 错误保留草稿、不可用/可用模型、模型请求体、旧计算结果隔离 | 验证前端接口契约；主验收的模拟上下文不启动本地 LoRA 推理任务 |
| 独立真实本地模型检查 | 实际 `local-lora` 回答、引用、思考至待机、忙碌时禁选、切回云端后保留原回答模式 | 另见 `reports/browser_local_check_v4.json`；不计入主验收模拟模型调用，也不证明领域准确性 |
| 模拟浏览器语音事件 | 聆听、朗读、结束与 Avatar 状态同步 | 不验证麦克风硬件、识别准确率或扬声器可听效果 |
| 人工截图复核 | 桌面/移动工作区、聊天、Avatar、计算器 | 视觉判断与自动断言互补，不声称 WCAG 完整认证 |

计算基准：初始 10,000、名义年利率 5%、10 年、每月月末追加 500 → 94,111.23；相同情景利率为 0 → 70,000.00；贷款 100,000、年利率 6%、30 年 → 月供 599.55；月收入 5,000、支出 6,000 → 储蓄率 −20%。

## 5. 本轮结果与文件

最终验收通过 **33 项检查、12 个布局案例**（6 档宽度 × 中英双语），Edge 155.0.4283.45、Windows、headless，耗时 57.14 秒；正常路径的 JavaScript 页面错误与 console error 均为 0。报告中的完整源文件 SHA-256 用于确认验收对应的界面版本。

主验收真实提交两条问题：1440px 桌面中文复利问答约 5.97 秒，390px 移动英文分散投资问答约 6.98 秒，实际模式均为 `deepseek`，分别渲染了 `compound-interest` 与 `diversification` 来源。会话保存、重载、JSON 下载及自身测试会话清理均通过。单次延迟仅代表这次本地浏览器到服务的观察，不作为服务 SLA。

独立 Avatar 检查通过 12 项，包括实际 WebGL2/r187、五状态、原生 SVG、减少动效、销毁释放和强制 WebGL 失败回退。独立本地 LoRA 浏览器检查通过 6 项，实际模式为 `local-lora`，未产生 DeepSeek 请求。三份报告作用不同，不合并成模型准确率或覆盖率。

人工复核了最终桌面欢迎区、移动欢迎区、真实双语聊天、展开的移动 Avatar、桌面复利弹窗与移动预算缺口弹窗。三栏构图、黑金层级和金色曲线协调；窄屏内容自然换行，无横向溢出。计算器弹窗可内部滚动查看公式及假设。关键免责声明在各断点为 11px；主回答正文为 14px，模型说明和 Avatar 说明为 12px。

早期 QA 抓到风险/应急样例点击会直接发送的问题，已修为仅填入草稿并提示点击发送；最终检查验证样例不会自行产生请求。其余两次早期失败来自测试本身对原生 option 禁用状态及异步会话选择的断言方式，修正后再跑，未据此宣称应用故障。
