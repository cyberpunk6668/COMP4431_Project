# FinPilot Coinwise 浅色工作台

`/workspace` 使用 `#FAFAFA` 背景、`#0F172A` 主文字、`#64748B` 次文字与 `#D4AF37` 品牌金色。按钮使用由金色到铜金色的渐变，小字号金色文字使用更深的 `#805B1B`。聊天、计算器、模型面板和 Avatar 共用这组颜色与本地 Inter 字体。

首次打开 v5 工作台时，旧版 `gold-v4` 主题迁移到浅色，并写入 `finpilot-workspace-skin=coinwise-v5`。之后，右上角的主题开关会保存用户明确选择的深色或浅色。

桌面保留会话导航、对话区和 Avatar 面板。移动端把导航收进抽屉，Avatar 可展开，计算器使用可滚动弹窗。回答进入、模型确认、计算结果和曲线继续提供状态反馈。顶部暂停控件与系统减少动效设置可停止非必要动画。

## 复验方法

本地服务启动后运行以下命令。`--theme light` 会把结果写入 v5 目录，并拦截真实聊天请求。

```powershell
.venv\Scripts\python.exe scripts\check_workspace_v4.py --theme light --base http://127.0.0.1:8000
```

- 实际浏览器和本地后端验证主题迁移、偏好持久化、320 至 1920px 中英布局、触摸导航、2D/3D Avatar、暂停动效、会话操作与公式计算。
- 独立模拟请求验证聊天等待和失败恢复、来源渲染、模型切换、计算器旧响应隔离以及浏览器语音事件联动。
- v5 验收报告保存在 `reports/workspace_check_v5.json`，截图保存在 `reports/screenshots/workspace-v5/`。
- v4 的真实 DeepSeek 与本地 LoRA 调用记录见原版报告。本轮检查的语音范围为模拟浏览器事件。

## 验收结果

Windows 上的 Edge 通过 31 项检查和 12 个布局案例。320、390、768、1024、1440、1920px 各检查中英两种语言，工作区与计算器均通过。页面错误、正常流程控制台错误与真实模型请求均为 0。

实际计算接口返回复利终值 94,111.23、零利率终值 70,000.00、贷款月供 599.55 和预算储蓄率 −20%。会话创建、选择、空会话 JSON 导出与删除通过，验收创建的会话已清理。

人工查看了 1440px 桌面和 390px 移动工作台、聊天来源、展开的移动 Avatar，以及复利和预算弹窗。浅色背景与金色层级在这些视图中一致，未发现横向裁切。语音、模型切换与聊天故障使用模拟事件或响应，计算器和会话操作使用真实本地接口。
